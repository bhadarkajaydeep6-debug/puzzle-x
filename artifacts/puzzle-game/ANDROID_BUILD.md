# Puzzle X — Android APK Build Guide

## TL;DR (fastest path to a debug APK)

```bash
# Prerequisites: Node 18+, pnpm, Java 17+, Android Studio with SDK 34
# ANDROID_HOME must be set

git clone <your-repo>
cd <project-root>
pnpm install
cd artifacts/puzzle-game
npx cap add android
bash android-config/apply-android-config.sh
bash android-config/build-android.sh    # choose 1 for debug APK
adb install android/app/build/outputs/apk/debug/app-debug.apk
```

## Option A — Local machine build

### Prerequisites

| Tool | Version | Download |
|---|---|---|
| Node.js | 18+ | https://nodejs.org |
| pnpm | 9+ | `npm i -g pnpm` |
| Java JDK | 17+ | https://adoptium.net |
| Android Studio | Latest | https://developer.android.com/studio |
| Android SDK | API 34 | Via Android Studio → SDK Manager |

Set `ANDROID_HOME`:
```bash
# macOS/Linux — add to ~/.zshrc or ~/.bashrc
export ANDROID_HOME=$HOME/Library/Android/sdk  # macOS
export ANDROID_HOME=$HOME/Android/Sdk          # Linux
export PATH=$PATH:$ANDROID_HOME/tools:$ANDROID_HOME/platform-tools
```

### First-time setup

```bash
# 1. Install dependencies
pnpm install

# 2. Navigate to the game
cd artifacts/puzzle-game

# 3. Add Android platform (generates the android/ directory)
npx cap add android

# 4. Apply all Puzzle X config patches
bash android-config/apply-android-config.sh
```

### Build commands

```bash
# Debug APK (fast, for testing — sideload or ADB install)
bash android-config/build-android.sh    # choose 1

# Signed release APK
bash android-config/build-android.sh    # choose 2

# Signed AAB for Play Store
bash android-config/build-android.sh    # choose 3

# Open Android Studio for visual debugging
bash android-config/build-android.sh    # choose 4
```

### Direct Gradle commands (after first-time setup)

```bash
cd artifacts/puzzle-game

# Rebuild web assets
pnpm run build:android

# Sync into Android project
npx cap sync android

# Build debug APK
cd android && ./gradlew assembleDebug

# Build release APK (requires env vars)
KEYSTORE_FILE=puzzle-x-release.jks \
KEYSTORE_PASS=your_pass \
KEY_ALIAS=puzzlex \
KEY_PASS=your_key_pass \
./gradlew assembleRelease

# Build AAB for Play Store
./gradlew bundleRelease
```

### Install on device

```bash
# USB ADB install
adb install android/app/build/outputs/apk/debug/app-debug.apk

# Or copy the APK to your phone and open it (enable "Install unknown apps")
```

## Option B — GitHub Actions (no local Android SDK needed)

Every push to `main` automatically builds a debug APK. To enable signed release
builds, add these secrets to your GitHub repo:

**Settings → Secrets and variables → Actions → New repository secret**

| Secret | How to get it |
|---|---|
| `KEYSTORE_BASE64` | `base64 -i puzzle-x-release.jks \| pbcopy` (macOS) |
| `KEYSTORE_PASS` | Password you set when creating the keystore |
| `KEY_ALIAS` | `puzzlex` |
| `KEY_PASS` | Key password you set |
| `VITE_ADMOB_BANNER_ID` | From AdMob Console (optional — uses test IDs otherwise) |
| `VITE_ADMOB_INTERSTITIAL_ID` | From AdMob Console (optional) |
| `VITE_ADMOB_REWARDED_ID` | From AdMob Console (optional) |

**Triggering a release build manually:**

1. GitHub → Actions tab → "Puzzle X — Android Build"
2. Run workflow → Select `release` or `both`
3. Download the APK/AAB from the workflow's Artifacts section

## AdMob setup

### Test build (already configured)

The project uses Google's official test ad unit IDs by default. These work
immediately — no AdMob account needed for testing.

### Production build

1. Create an AdMob account at https://admob.google.com
2. Add a new app: **Puzzle X** (Android)
3. Create three ad units: Banner, Interstitial, Rewarded
4. Copy the IDs into `.env.production` (use `.env.production.example` as a template)
5. Update `capacitor.config.ts`:
   - Replace `AdMob.appId.android` with your real App ID
   - Set `initializeForTesting: false`
6. Update `android/app/src/main/AndroidManifest.xml`:
   - Replace the `APPLICATION_ID` meta-data value with your real App ID

### How ads are integrated

| Ad type | When it shows | File |
|---|---|---|
| Banner | Persistent bottom bar while in-game | `src/lib/nativeAdManager.ts` |
| Interstitial | Every 5 levels completed | `src/gameAds.ts` |
| Rewarded | "Watch ad for 20 coins" or "Watch ad for hint" | `src/gameAds.ts` |

On web/browser: native ads are no-ops; simulated web ad UI is shown instead.
On Android: real AdMob native ads via `@capacitor-community/admob`.

## Touch controls

Touch is handled natively in `src/pages/Game.tsx`:

- **Tap**: `onMouseDown` on each tile → moves it if adjacent to empty slot
- **Swipe**: `onTouchStart` / `onTouchMove` / `onTouchEnd` track delta and
  trigger moves when the gesture crosses a threshold
- **Haptics**: `hapticLight()` on each successful move, `hapticMedium()` on win

No special Android config needed — Capacitor's WebView passes touch events
through to the HTML/JS layer transparently.

## Cloud save

Cloud save is implemented in `src/lib/syncManager.ts` using the `/api/save`
endpoint on the Express API server (`artifacts/api-server`).

- **On Android**: the device calls the cloud endpoint over HTTPS (the
  `network_security_config.xml` enforces this)
- **Offline**: `src/lib/offlineManager.ts` detects connectivity via
  `@capacitor/network` and queues saves locally until back online
- **Sync code**: players get a 6-character code shown in Settings → Cloud Backup;
  entering it on another device restores all progress

## APK size optimisation summary

| Technique | Saving |
|---|---|
| ABI splits (arm64-v8a only APK) | ~50% vs universal APK |
| Resource shrinking (`shrinkResources true`) | ~15% |
| ProGuard/R8 minification | ~25% |
| Vite chunk splitting (vendor / motion / ui) | Faster load, no size increase |
| terser 2-pass compression | ~5–10% JS reduction |
| `drop_console: true` | Removes all console.log calls |
| `assetsInlineLimit: 2048` | No large base64 blobs |

**Estimated final APK sizes:**
- `app-arm64-v8a-release.apk` — **~9 MB** *(most modern phones)*
- `app-release.apk` (universal) — **~18 MB**
